MiniSERP

API live

A Ruby on Rails API that turns a search-engine results page into clean, structured JSON — parsed with Nokogiri, cached in MongoDB, with block detection and rate limiting. Type a query below; it calls the same public endpoint any client would.

What you just called

One GET request, four layers behind it

Resilient parsing

Google's result wrapper changed from div.g to div.MjjYud. The parser tries ordered selector strategies, then falls back to pure structure — find each heading, walk up to the nearest linked block — so a class rename doesn't return an empty array.

Cache, not re-scrape

Every result is stored in MongoDB with a TTL. Run the same query twice and the second response comes back cached: true with an age counter, served from the database.

Blocks aren't garbage

When a search engine serves an anti-bot page instead of results, it's detected by content and structure and returned as 403 blocked — never as a plausible-looking empty result set.

Offline by design

This demo reads saved HTML fixtures — no live search engine is called. A live HTTP transport with retry and backoff is implemented and tested behind one config value.
